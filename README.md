# VANGUARD Runtime

Modular execution runtime for the VANGUARD system, built around explicit contracts and verifiable execution.

## Status

This repository is an implementation incubator. The runtime architecture is not considered final merely because code exists here.

Adoption requires explicit evidence and confirmation.

## Initial boundary

The first implementation slice will establish:

ExecutionRequest -> execution boundary -> ExecutionResult

with explicit errors, verification hooks, and contract compatibility.

## Governing principle

> Probability may enter the loop, but it does not leave the loop as truth without confirmation.
